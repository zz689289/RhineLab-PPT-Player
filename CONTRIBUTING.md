# Contributing

Please include the Windows version, GPU, display scaling, PPTX/PDF source type, reproduction steps, and whether a redacted screenshot can be provided.

Never upload private or confidential PPT/PDF files, account information, tokens, browser profiles, logs, or local absolute paths. Prefer a minimal synthetic or redacted reproduction.

Check `docs/KNOWN_ISSUES_zh-CN.txt` before proposing work. The README categories are not a replacement for the original user-authored list.
